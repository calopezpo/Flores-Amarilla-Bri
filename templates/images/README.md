# Carpeta de imágenes

Pon aquí tus fotos o GIFs (por ejemplo `flores.gif`, `nosotros.jpg`).

## Cómo referenciarlas en index.html

Ruta relativa desde `index.html`:

```html
<img class="photo" src="templates/images/NOMBRE-DEL-ARCHIVO.jpg" alt="Descripción de la imagen">
```

Ejemplos ya dejados como comentario dentro de `index.html`, en la Pantalla 2 (flores) y la Pantalla 3 (foto de ustedes).

La clase `.photo` (definida en `css/style.css`) ya deja la imagen con bordes redondeados y una sombra suave, así que solo necesitas cambiar el `src`.
